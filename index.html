ملاحظة صلاحيات

لا تجعل حسابات الطلاب مسؤولة عن الإدارة. عيّن المدير يدويًا من SQL بعد التأكد من البريد الإلكتروني الصحيح.

إعداد قاعدة البيانات (مرة واحدة)

انسخ SQL التالي إلى Supabase → SQL Editor ثم اضغط Run. هذا ينشئ جداول مساعدة فقط ولا يحذف أو يغيّر جداول المواد السبعة الموجودة.


 
تعيين حساب المدير
بعد إنشاء حساب المدير وتأكيد بريده، غيّر البريد في الاستعلام التالي وشغّله مرة واحدة من SQL Editor:
update public.profiles set role = 'admin' where id = (select id from auth.users where email = 'ضع-بريد-المدير-هنا');

 
بعد تشغيل SQL، أنشئ Storage bucket باسم avatars واجعله Private، ثم اضبط سياسات التخزين قبل تفعيل رفع الصور. رفع الصور غير مفعل في هذه النسخة. لا تشارك أي مفتاح سري أو service_role داخل هذا الملف.
