# منصة الفرقة الثانية شبكات كهربية

واجهة عربية متجاوبة لمنصة طلاب الفرقة الثانية – شعبة شبكات كهربية بالمعهد الفني الصناعي العالي بقويسنا.

## الملفات
- `index.html`: الواجهة الرئيسية (HTML/CSS/JavaScript) وتستخدم Supabase JS v2 من CDN.
- `supabase_setup.sql`: إنشاء الجداول المساعدة وسياسات RLS.
- `firebase.json`: إعداد Firebase Hosting للنشر من جذر المشروع.

## إعداد Supabase
1. افتح مشروع Supabase ثم SQL Editor.
2. نفّذ محتويات `supabase_setup.sql`.
3. تأكد من وجود حساب المدير في Authentication → Users ومن أن صفه في `public.profiles` يحمل `role = 'admin'`.

إعدادات الاتصال الحالية موجودة في `index.html` (URL ومفتاح publishable). المفتاح publishable مخصص للواجهة، ولا تضع أي مفتاح secret أو service_role في هذا الملف.

## النشر على Firebase Hosting
المشروع عبارة عن موقع ثابت. استخدم Firebase Hosting واجعل مجلد النشر هو جذر المشروع (`.`)، وملف البداية `index.html`.

## ملاحظات الحالة
- تسجيل الدخول والتسجيل وإدارة الإعلانات والمواد وتذاكر الدعم تعتمد على اتصال Supabase وإعداد الجداول والسياسات.
- جداول المواد السبعة الموجودة مسبقًا لم تُربط بعد؛ يلزم معرفة أسماء الجداول/أعمدتها الفعلية.
- رفع الصورة الشخصية لم يكتمل بعد.
- اختبر الإعدادات في مشروعك قبل مشاركة الموقع مع الطلاب.
